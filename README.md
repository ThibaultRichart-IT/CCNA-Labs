# CCNA Labs

## Présentation

Ce dépôt regroupe les laboratoires que je réalise dans le cadre de ma préparation à la certification Cisco CCNA.

Pour chaque laboratoire, je documente :
- la topologie utilisée ;
- les configurations réalisées ;
- les commandes importantes ;
- les vérifications effectuées ;
- les notions que j'ai retenues.

## Objectif

Au-delà de la préparation au CCNA, ce dépôt me permet de conserver une trace de mon apprentissage et de partager mon travail de manière claire et structurée.

## Laboratoires

Les laboratoires seront ajoutés progressivement.
